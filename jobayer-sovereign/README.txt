PUBLISH FOR FREE WITH GITHUB PAGES
1. Sign in to GitHub or create an account at https://github.com/
2. Create a new PUBLIC repository named: jobayer-sovereign
3. Upload index.html to the repository's root (top-level) folder and commit the change.
4. Open the repository's Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish. Your address will look like:
   https://YOUR-GITHUB-USERNAME.github.io/jobayer-sovereign/
   Replace YOUR-GITHUB-USERNAME with your actual GitHub username.
